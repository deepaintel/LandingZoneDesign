# APM Authoring Convention

## 1. Purpose

This repository manages AI agent customization (instructions, skills, and prompts) through
[Microsoft APM](https://github.com/microsoft/apm) (Agent Package Manager). `.apm/` is the single
source of truth. Files under `.github/instructions/`, `.github/copilot-instructions.md`,
`AGENTS.md`, and `.claude/rules/` are **generated build output** and must never be hand-authored.

## 2. Source of Truth

- Instructions live under `.apm/instructions/*.instructions.md`.
- Skills live under `.apm/skills/<skill-name>/SKILL.md`.
- Prompts (if used) live under the equivalent `.apm/` location for prompts.
- `apm.yml` declares the deployment `targets` (currently `claude` and `copilot`) and `includes: auto`,
  which causes `apm compile` to discover everything under `.apm/` automatically.

## 3. Generated Output — Do Not Hand-Edit

The following are produced by `apm compile` and must not be created or edited directly:

- `.github/instructions/*.instructions.md`
- `.github/copilot-instructions.md`
- `AGENTS.md`
- `.claude/rules/*.md`

Each generated file carries a header comment (`<!-- Generated by APM CLI from .apm/ primitives -->`)
confirming its origin. Manual edits to these files will be silently overwritten and out of sync
with `.apm/`, and will fail `apm audit --ci` in CI (see `.github/workflows/ci.yml`).

## 4. Required Workflow for New or Changed Instructions/Skills

1. Create or edit the source file under `.apm/instructions/` or `.apm/skills/`.
2. Run `apm compile` locally to regenerate the distributed output files.
3. Run `apm audit --ci` locally to confirm the generated output matches the `.apm/` source before
   committing (this is the same check CI enforces).
4. Commit both the `.apm/` source change and the regenerated output files together.

## 5. CI Enforcement

`ci.yml` installs the pinned APM CLI version and runs `apm audit --ci`. This step fails the build
if generated output is missing, stale, or was edited independently of its `.apm/` source. Do not
attempt to bypass this by hand-editing the generated files to make them "match" — always regenerate
through `apm compile`.

## 6. Scope

This convention applies to every instruction, skill, and prompt in this repository. It does not
change the content-level governance rules already defined by the other `.apm/instructions/*` files;
it only governs *where* those files are authored and *how* they reach `.github/` and `.claude/`.
