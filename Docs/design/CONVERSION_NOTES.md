# Conversion notes

These eight Markdown files were converted from the supplied Word documents without intentional technical or editorial rewriting. The original DOCX files remain unchanged.

- Main-body graphics are linked using portable relative paths under `assets/`.
- All images embedded in the DOCX packages (including unreferenced header/footer images and logos) are additionally preserved under `assets/<document>/embedded-original/`.
- Word-specific visual layouts, page breaks, headers/footers, and complex merged-cell tables may not render identically in GitHub Markdown. Markdown tables and original wording should be visually reviewed before replacing approved documents.
- Word-generated tables of contents and page numbers can be stale after conversion; the source wording was preserved.
- No repository files were changed.
